# 🎮 RPS Arena – Rock, Paper, Scissors Game

### InfozaTech Python Internship | Task 2

RPS Arena is a Python-based Rock, Paper, Scissors game developed as part of my **Python Programming Internship at InfozaTech**.

The project allows users to play against the computer through an interactive command-line interface. The computer randomly selects its move, and the program determines the winner based on the traditional rules of Rock, Paper, and Scissors.

## 🚀 Features

- **User Interaction:** Players can choose Rock, Paper, or Scissors.
- **Random Computer Selection:** The computer randomly generates its choice.
- **Winner Detection:** Automatically determines whether the player wins, loses, or draws.
- **Score Tracking:** Maintains the scores of both the player and computer.
- **Multiple Rounds:** Allows users to play multiple rounds.
- **Final Scoreboard:** Displays the final scores after the game ends.
- **Input Validation:** Handles invalid user inputs.

## 🛠️ Technologies Used

- Python 3
- Random Module
- Conditional Statements
- Loops
- Functions
- User Input Handling

## 🎯 Game Rules

| Player Choice | Beats |
|---|---|
| Rock 🪨 | Scissors |
| Paper 📄 | Rock |
| Scissors ✂️ | Paper |

- If both players select the same option, the round is a draw.
- If the player's choice beats the computer's choice, the player wins.
- Otherwise, the computer wins.
